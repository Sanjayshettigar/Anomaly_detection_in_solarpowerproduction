# Anomaly_detection_in_solarpowerproduction

 This project is a machine-learning and deep-learning based anomaly detection system for solar power generation. The GitHub repository contains the complete workflow, starting from loading the solar power dataset and preprocessing the data, followed by feature engineering and model training. The dataset contains time-series information such as date, hour, production value, source type, weekday, and month. During preprocessing, missing values are handled, categorical features are converted into numerical form, production values are normalized, and 24-hour sliding windows are created for the sequence-based models. We then train multiple models independently, including FFNN, LSTM, LSTM Autoencoder, and Isolation Forest. FFNN performs feature-based classification, LSTM captures temporal dependencies, the LSTM Autoencoder detects anomalies using reconstruction error, and Isolation Forest identifies unusual data points as outliers. The outputs from these models are then combined and given to an XGBoost meta-ensemble, which generates the final anomaly probability and classification. The repository also contains the evaluation and visualization part, where we calculate metrics such as accuracy, precision, recall, F1-score, and ROC-AUC, and generate graphs such as ROC curves, confusion matrices, and time-series anomaly plots. The overall workflow of the repository is therefore dataset preparation, preprocessing, feature engineering, individual model training, XGBoost-based ensemble prediction, evaluation, and visualization.
